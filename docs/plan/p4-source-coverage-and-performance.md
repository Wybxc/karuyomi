# P4 Source 覆盖、性能与可访问性

## 目标与状态

在已验收产品链路上持续扩大真实 Source 覆盖，改善图像格式、交互、内存和可访问性。状态：**少量样本已有分项证据，P4 未验收**。P0 的移动与图片基础门不能推迟到 P4；本阶段扩大覆盖，不替代 [P0](p0-runtime-and-reading.md) 的进入条件。

## 已有基础

- 少量当前上游包已真实 AOT、完整性校验和浏览器初始化；MangaDraft 有真实网络元数据结果及源站挑战失败记录。
- 历史 release9 研究覆盖、固定输入语义和性能结果保留为历史证据；不能外推为当前全部上游包、真实阅读或手机表现。
- [AOT 包体方案](../AOT-SIZE.md)已采用共享材料与 gzip；本地全量发布默认 `compiled_unverified`，不据发布数量累加运行覆盖。
- [iOS 模拟器真实阅读采集](../verification/reader-baseline-ios.md)已保留固定 v6 Arknights 的首图、翻页、竖向滚动、切章、引擎帧和 App 进程 RSS 原始记录。单轮 debug 样本用于复验采集方法；同条件冷热分布、真机、长图、CPU 与 WebContent/GPU 合计峰值仍待测量。

## 待办

1. 建立按 Source、扩展版本、host/材料版本、平台/浏览器和 Cloudflare 出口记录的验证矩阵；分开记录编译、初始化、六项操作、图片处理、完整阅读、登录/验证及存储恢复。
2. 扩大直图、特殊请求头、解密/重排、特殊图片格式与较重包样本；空结果、失败、跳过及原因分别记录，不把前置跳过或合成响应计入在线通过。
3. 测量冷/热启动、有效首图可见时间、切章延迟分布、滑动/缩放帧耗时、长任务、能耗和持续阅读合计峰值；区分 TeaVM、传输队列、插件主动整段读取、图像解码与 GPU。
4. 按真机数据调整扩展执行槽、图片并发/窗口、超长图降采样/分片；可选常量字典、压缩或编译档位优化须先有正确性和代表包 A/B，不重开框架/引擎选型。
5. 覆盖 360px 窄屏、约 44px 触控目标、键盘焦点/快捷键、可见标签、非颜色状态和 reduced-motion；系统能力不足时正常降级，不禁止整页浏览器缩放。

## 验收

- 每条支持声明可定位到版本和实际环境；源站挑战、账号、地区、桥能力缺失与运行时缺陷分开归因。
- 固定响应与真实网络结果分开，重复样本不伪装为独立设备；桌面/模拟器结果不替代物理移动设备。
- 优化保持完整 DTO、请求/图片语义和资源生命周期；测得收益与实际限制同时记录。
- 可访问性核心操作和连续阅读通过声明设备验证，不增加暂缓的更新、下载、历史统计或其它外围模块。
