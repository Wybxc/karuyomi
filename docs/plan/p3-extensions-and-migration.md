# P3 扩展管理与源迁移

## 目标与状态

将正式 AOT 工具链提供的当前构建变成可用的仓库/扩展管理、Source 设置与用户确认的源迁移流程。状态：**收藏源与快捷打开已实现待独立客户端验收，包内语言筛选已实现待实际 Source/平台验收，其余扩展管理与迁移待实现**。构建注册和浏览中的包/Source 选择属于工程基础。依赖 [P0](p0-runtime-and-reading.md) 运行边界和 [P1](p1-library-and-progress.md) 书架状态；发布流水线由[工程计划](engineering-and-release.md)维护。

## 已有基础

- 官方上游 submodule、按包 builder、manifest/provenance、失败隔离与最新版 Static Assets 工程入口已有实现。
- manifest 记录包/版本、Source IDs、ABI、storage schema 与资源身份；运行时按构建/代次隔离并检查实际 Source IDs。
- 浏览入口能够从静态索引选择当前构建；这不等于用户安装、升级、回滚或迁移已完成。
- 收藏源复用生成全局设置、D1、CAS 与原请求幂等，正式浏览中可收藏/取消并快捷打开；设计见[收藏源](../design/source-favorites.md)，工程与独立客户端门见[验证记录](../verification/source-favorites.md)。

## 待办

1. 实现仓库添加、扩展安装/卸载、手动升级、当前构建固定及用户可见错误。无 AOT 产物时明确待构建/不支持，不从网页启动远程编译。
2. 明确切换前的执行槽排空、取消与存储写锁，避免跨标签页/实例同时写相同可变 namespace；失败时恢复可用状态。
3. 服务器仅保留每包最新可用构建。客户端检查索引、切换版本并清理旧缓存；不承诺远端历史版本回滚，不维护旧协议或旧材料兼容层。
4. 开放 Source 自定义筛选与 typed preferences：开关、文本/密码、单/多选、分组、依赖项与刷新；不把 Android 自定义 Activity 设置页当成已支持。敏感值与可同步设置分离。
5. 收藏源与快捷打开已实现，补实际独立客户端及索引更新验收；包内语言筛选已实现，继续全目录语言筛选、能力提示及有界跨源搜索，各源独立返回、可取消，一个慢源不阻塞全部结果。仅声明实际验证的登录/验证码/脚本能力。
6. 实现源迁移：搜索候选 → 用户确认作品 → 预览章节映射 → 创建目标收藏 → 复制明确匹配的分类/已读/书签。章节号、标题、扫描组辅助匹配；模糊项不自动标已读。

## 收藏源里程碑

**可跨端同步的收藏源与快捷打开：已实现待独立客户端验收。** 收藏项以 `packageName + sourceId` 为稳定身份，名称和语言作显示快照；不保存 buildId/generation。列表复用全局设置权威路径，校验字段、128 项限额和组合身份唯一性；全局设置修改保留主题、阅读偏好和收藏，丢响应复用原请求，冲突后由用户重新确认。

正式浏览中可收藏/取消，快捷入口按当前会话已读取的静态索引打开构建，再确认原 Source ID；缺包或缺源明确提示并保留记录，不任意打开其它源。各阶段共用 busy 与身份/页面检查，未确认原操作有独立展示和显式重试。实现及证据分别见[设计](../design/source-favorites.md)与[验证](../verification/source-favorites.md)。独立客户端、构建更新后的稳定身份与打开期间切页/换身份继续验收，组件通过不等于 P3 整体完成。

## 当前功能里程碑

**当前已加载包内的 Source 语言筛选：已实现待实际 Source/平台验收。** 复用正式运行时返回的 `SourceInfo.lang`，在现有包内来源列表提供语言选择、匹配数量和清除入口；只投影已取得的 Source 列表，不为筛选发 Source 请求或写业务状态，隐藏条目不改变当前已打开来源。切换包或 generation 后重置为“全部”；未加载包不显示筛选，正式空 `sources` 仍由运行时加载错误路径拒绝；验收多语言、隐藏当前选中来源和切换会话后的筛选状态。设计见[语言筛选](../design/source-language-filter.md)，实际工程与平台结果见[验证记录](../verification/source-language-filter.md)。

全目录语言筛选仍缺静态索引的完整 Source 名称/语言，不能把已加载包或收藏快照当成全目录；typed filters/preferences 也尚缺正式控制合同，继续保留原待办。本里程碑只补既定语言筛选范围内的直接入口，不扩建假设的源能力通用框架。当前 host 指纹包含业务协议与生成代码，其变化继续进入正式增量构建判定，不能据此承诺无需重建 AOT。

## 下一功能里程碑

**typed Source 筛选（未开始）。** 从原 Source 的 `getFilterList` 枚举有界 Filter 子类树，通过正式协议描述可编辑状态；应用时按绑定的列表快照与有界路径回写原具体子类的 `state`，保留扩展业务中的 `filterIsInstance` 语义，不能用通用替代对象冒充原 Filter。筛选状态绑定当前 Source、generation 与清单快照，切换会话后旧引用失效。

显式应用后调用正式 `search`，空 query 也必须走搜索，不能自动退为热门；后续分页复用同一份已应用状态。完成类型与路径/大小/数量校验、嵌套状态处理、取消和迟到结果边界后，使用真实 Source 验证原具体子类状态被业务识别，以及空 query 与后续页沿用筛选。组件或 JVM/宿主适配测试不替代实际在线筛选验收。现有三包中的 CuuTruyen 可作代表候选：上游使用 `Group<TagCheckBox>` 和远端动态标签，适合验证重置、具体子类和空 query；已有默认浏览与图片证据不能覆盖筛选。

typed preferences 另作后续工作，本里程碑不宣称已支持 Source 设置页。扩展管理的启用/卸载、手动更新、切换前排空、旧缓存清理与失败恢复，以及全目录元数据、有界跨源搜索和用户确认迁移继续保留既有待办；不以零散界面改动代替这些完整流程。

## 验收

- 安装/手动升级/卸载与旧缓存清理流程有真实构建用例；中断、拒绝、存储冲突或缺失材料均明确失败，不能以隐式旧版本 fallback 掩盖问题。
- 已开放的筛选和设置逐项有真实 Source 证据；敏感项不泄漏到公开资源或多设备同步。
- 源迁移预览与最终写入一致，原条目完整保留，用户另行决定移除；不自动快照、不依赖备份/追踪模块。
- Source URL/ID 保持稳定；换域和来源变化走显式规则，不用全局解码或按标题去重制造新身份。
