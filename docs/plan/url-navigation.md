# Web 地址与站内导航

## 目标与状态

让 Karuyomi 的可访问页面由同一套路由驱动。浏览器直接访问、刷新、前进后退和站内点击可到达同一个页面。宽屏保留详情分栏，窄屏提供整页。实现和验收以[路由设计](../design/url-navigation.md)为准。

## 任务与验收

- [x] 主入口、漫画源、跨源搜索、作品、章节、扩展管理和全局设置详情接入路由。
- [x] 在 Worker 为应用路径返回入口，保留 API 鉴权、登录回调和静态资源缺失语义。
- [x] 用 Flutter 回归测试核对直接打开与重开、宽窄屏切换、引擎收到前进后退时的路由切换、站内返回、同账号作品恢复和异账号隔离。
- [x] 核对章切换更新地址、已确认进度恢复、迟到结果和图片会话清理。
- [x] 通过正式 Web 构建及官方隔离 Worker 验证深链接 GET、HEAD 和静态资源响应。
- [ ] 在内置浏览器实测地址栏、刷新和前进后退。2026-11-25 的两次浏览器控制请求均超时。已通过的验证见[验证记录](../VERIFICATION.md)。
