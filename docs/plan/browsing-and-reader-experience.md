# 浏览与阅读体验改进

## 目标与状态

按 2026-11-24 的用户要求完成扩展、浏览、阅读和桌面布局八项改进。扩展安装意图、浏览记录及可同步的源设置沿现有 Worker API 和 D1 确认路径。八项已在功能分支接入。工程与平台验收分别记录在 [VERIFICATION](../VERIFICATION.md)。

## 实施与验收

- [x] **扩展批量更新**。在扩展管理显示所有可更新项的数量，依次准备同仓库的候选，保留启停状态，一次确认成功项。组件测试已覆盖取消、部分失败和另一设备并发修改账户设置。
- [x] **浏览记录**。记录主动打开的作品详情与直接进入阅读的访问，包括未收藏作品。按账户保留最近访问的 100 部作品，同一作品更新最近访问时间。验证时间排序、重新打开、删除或清空及另一会话读回。
- [x] **横向连续阅读**。横向分页和横向连续各支持从左到右、从右到左，纵向连续提供普通间距和无间距条漫。单页、双页及自动适配是分页布局选项。验收方向、顺序、章节边缘、模式切换与原图锚点恢复。
- [x] **阅读工具与画布布局**。上下工具栏和页码使用覆盖层，显隐与控件高度变化时保持画布矩形、图像尺寸、缩放和滚动偏移。验收中点触摸、键盘显隐和短屏控件滚动。
- [x] **精简非必要提示**。正常的同步及已保存状态静默完成；保存失败、未保存、冲突或登录失效提供直接的提示和操作。验收书架、设置、源设置和阅读主入口。
- [x] **浏览前配置漫画源**。源列表提供配置入口，打开设置时只准备配置会话。每次编辑保存账户可同步字段或本机字段。关闭配置后用已确认值进入或刷新浏览。验证同账户读回，以及等待编辑时未请求热门或最新列表。[Source 设置计划](source-preferences.md)
- [x] **可查看并复制扩展报错**。漫画源与扩展管理的失败入口可以打开详情，由用户复制脱敏后的操作、错误码和描述。验证入口属于当前失败请求，复制内容与详情一致。
- [x] **统一桌面布局**。侧栏与内容纵向分割，书架和浏览顶栏限定在内容列。宽屏详情在右列拥有自己的顶栏，窄屏详情显示独立页面顶栏。点开作品后立即显示详情标题，加载、失败与重试在详情内呈现。验收书架、浏览、设置、历史和详情的栏位、回退和尺寸切换。
- [x] **统一导航顺序与浏览语言筛选**。侧栏与底栏依次为书架、历史、浏览、扩展、设置。浏览可同时选择多种语言，按实际漫画源过滤，同一扩展内的其他语言和收藏源也遵循筛选。设备保存语言偏好，切换入口、账户或重开应用后继续使用。验收键盘切换、短屏大字号、扩展入口和多语言扩展的过滤结果。
- [x] **校正错误提示**。现有通用捕获把多种运行时故障映射为“漫画源请求失败”。区分登录、扩展或运行时、传输及实际 Source 错误。未知原因使用中性的操作失败提示，验证设置准备或运行时错误不会被显示为上游失败。

## 阅读模式划分

账户与单漫画设置以及阅读页快捷项按维度提供选择。排布方向分横向和纵向。横向可选分页或连续滚动，页序可选从左到右或从右到左。纵向采用连续滚动，可选有间距或无间距。分页时可选自动、单页或双页，图片适配与裁白各自独立。

排布、推进、页序和间距组成六种有效组合。横向分页的单页和双页分别计算时，共有八种固定呈现，自动布局随视口在单页和双页间选择。[阅读设置设计](../design/reader-settings.md)

## 交付门槛

工程检查覆盖格式、Dart、业务协议、Workers、数据库迁移和 Web 构建。内置浏览器的本轮验收因控制连接超时保留待验。真实浏览器中的宽窄屏入口、Web 与原生设备的历史同步和源设置读回仍需分项验收。
