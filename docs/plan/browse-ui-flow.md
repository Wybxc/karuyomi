**状态：本轮 UI 已上线，工程、Web 分项验收及最小生产检查完成。** 2026-11-12，用户采纳[UI 状态流程](../design/extension-browse-ui-flow.md)，要求据此修改 Karuyomi。已将面向漫画源的浏览、扩展维护、仓库和本机存储分开，展示加载、空态、局部失败及账户操作恢复。原生验收保持停止。

账户安装意图、设置、收藏和书架仍沿既有 Worker API + D1 确认路径。继续复用正式下载、精确构建门禁、取消、关闭和资源清理，不新增客户端业务库或未确认写入队列。原生验证保持停止；用户已授权本机运行 Flutter 分析、回归和 Web 构建，只有扩展 AOT 编译放到远端。本任务复用已有扩展产物，不触发 AOT。

- [x] 扩展列表按需要处理、已安装、可安装分组，主列表只呈现名称、语言、状态和主操作；详细版本、原始身份与诊断进入详情。
- [x] 仓库管理与本机存储为二级页面；添加/移除/换仓仍明确确认，副本清理不改变账户安装关系。
- [x] 安装、更新、启停和卸载分别呈现准备、保存、结果未知、冲突、已确认与清理未完成；原请求恢复保持现有幂等和 CAS 合同。
- [x] 源内作品区分首屏、新查询、刷新和追加；失败不清空已有结果，封面与书架标记走既有数据/资源路径。普通 Source 缩略图尚无正式资源通道，当前保留占位；已确认自定义封面正常展示。
- [x] 搜索、筛选、设置及热门/最新入口按实际能力显示，返回详情后保留列表上下文；变更查询不接受旧结果覆盖。
- [x] 跨源搜索保留明确选择、每源进度和局部结果，停止/离开等待清理；失败和达到限额各有操作入口。
- [x] 补充有意义的导航和状态回归，核对原收藏、设置、书架、详情与阅读测试的调用路径。
- [x] 完整格式检查、Flutter 严格分析/回归和正式 Web 构建通过，并用内置浏览器验收实际页面与关键操作；证据记录实际环境。

## 验收条件

1. 用户可以在漫画源列表一次选择进入作品，无须手工打开扩展再选源；未安装或停用的扩展不能被新入口绕过。
2. 本机缺副本显示准备状态；仅补齐同一已确认构建不提交账户安装，不静默升级或换仓。
3. 操作成功以服务器确认结果为准；冲突或确认未知不会伪报成功。卸载成功与本机清理失败可分别识别并恢复。
4. 初次加载、过滤无匹配、没有安装、请求失败、刷新失败、追加失败与没有下一页有不同状态；已有结果可以继续查看。
5. 漫画封面继续使用正式交付边界，失败为占位；普通源请求失败不被编造成登录或验证码需求。
6. 正常列表不暴露包名、构建 ID、摘要或运行槽；详情按需保留诊断和原操作内容。
7. 现有身份退休、跨源搜索清理、账户 CAS、停用门禁与阅读恢复的回归保持通过；实现与实际运行证据分开报告。
