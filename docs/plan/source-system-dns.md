# Source 系统 DNS 兼容

## 目标

支持调用 `OkHttpClient.Builder.dns(...)` 的原扩展继续构造请求。由现有 Worker 解析原域名并出站，保留 Source 的签名、Cookie、拦截器和有界正文。

## 状态

- [x] Java 宿主接受 DNS 配置，并继续使用现有中继的系统解析。
- [ ] 用固定上游提交补编哔咔漫画并核对正式产物。
- [ ] 用新产物验证原扩展能发起请求，单独记录真实 Worker 出站、登录、目录和封面结果。

## 验收

宿主回归确认自定义 DNS 设置可用于构造客户端，且保留 Source 的鉴权配置。原扩展能否在线使用由 Worker 对上游域名的实际连通性和站点响应决定。
