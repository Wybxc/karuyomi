## 当前交付顺序

1. **优先功能完整性。** 每个里程碑先实现正式协议、权威读写和用户入口，再集中验证；等待生产 Access 或设备环境时继续可独立完成的功能。[P1 的续读与详情恢复里程碑](p1-library-and-progress.md#下一功能里程碑)已实现，实际平台门另验；[P3 收藏源与快捷打开](p3-extensions-and-migration.md#收藏源里程碑)也已实现，工程与独立运行门见[记录](../verification/source-favorites.md)；[P3 当前包 Source 语言筛选](p3-extensions-and-migration.md#包内语言筛选里程碑)已实现；[静态目录语言筛选](p3-extensions-and-migration.md#静态目录语言筛选里程碑)已接入当前可用索引的 Source 名称/语言，不加载其它扩展，集中工程检查通过、实际 Source/平台待验收，工程及实际运行门维护在[记录](../verification/source-language-filter.md)；[P3 typed Source 筛选](p3-extensions-and-migration.md#typed-source-筛选里程碑)已实现并通过集中工程检查、两包 v5 AOT 及 CuuTruyen Web 动态筛选/分页分项，继续其它 Source/平台验收，后续按[扩展管理](extension-management.md)与[typed Source preferences](source-preferences.md)推进完整功能链路；typed preferences 正式 v6 合同、工程检查、Komiic AOT 与 Web 设置/新文档恢复分项通过，继续其它 Source 控件、Native 和生产验收；默认仓库扩展管理正式合同和入口已接入，已通过[独立集中工程检查](../verification/extension-management.md)、完整 Flutter 回归与构建，实际客户端门继续推进。[源迁移](source-migration.md)已接入正式搜索、章节预览和原子确认，独立集中工程检查、完整 Flutter 回归及构建通过；实际 Source、独立客户端和平台门继续验收。额外仓库已接入，当前三包 AOT、Web 管理及默认 xkcd 安装/阅读分项通过，按[子计划](additional-repositories.md)继续真实外仓与平台验收；能力目录及有界跨源搜索等既定范围继续保留，不为假设的性能需求增加额外机制。
2. P1/P2 已实现的分类、章节书签、阅读设置（含外观、输入、适配和裁白）、书架批量操作、范围已读/未读及自定义封面，沿用同一 Worker API + D1 确认路径。各主题的实现、集中工程证据和独立客户端待办以 [P1](p1-library-and-progress.md) / [P2](p2-sync.md) 链接的记录为准，不把已有入口当成完整日用验收。
3. 功能里程碑完成后运行相关严格分析、数据与正式组件回归、格式和构建，及时提交并推送；不因等待全套人工矩阵而积压已完成的功能。工程检查不能代替真实 Source、独立客户端、生产 Access 或目标设备证据。
4. 环境可用时集中补齐同一身份 Web/iOS/Android 的实际在线读写、同时写竞争、响应丢失的幂等恢复、前台重取与断网恢复，确认冲突不覆盖另一端状态、最远进度不倒退、旧 epoch 不覆盖重新阅读。既有配对分项及剩余平台门在 [P2](p2-sync.md) 维护；生产 Access 与真机的 [P0](p0-runtime-and-reading.md) 基础验收并行推进。

## 维护约定

- 状态使用“未开始、进行中、已实现待验收、已验收、讨论待定”，只有对应验收证据成立才标为已验收。
- 实现变化更新所属计划；影响优先级或依赖时再更新本索引。详细证据保留实际平台、浏览器和执行环境，历史 Safari 验证不能改称 Codex 内置浏览器验证。
- 未来浏览器交互按 [AGENTS](../../AGENTS.md) 使用 Codex 内置浏览器；历史证据保持原环境。
- [设计依据](../PLAN.md#设计依据)保留来源和决策背景，并随新决策更新。`docs/design/` 已解除冻结；当前计划沿用已确定的 Flutter + TeaVM 架构。
- 暂缓模块不预建页面、表或接口：自动/批量更新、离线下载、历史统计、tracker、本地漫画、备份恢复、应用内账号与隐私模块。
