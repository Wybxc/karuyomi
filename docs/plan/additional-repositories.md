# 额外扩展仓库

## 目标与状态

**状态：已实现，独立集中工程检查通过，实际平台待验收。** 在默认仓库扩展管理基础上，完成额外仓库的账户登记、只读预览、更新与移除、同包明确替换和完整运行来源隔离。设计见[额外扩展仓库](../design/additional-repositories.md)，上级见 [P3](p3-extensions-and-migration.md) 与[扩展管理](extension-management.md)。

## 实施范围

- 生成协议统一仓库设置、必填 CatalogReference、index repoId、准备/打开/会话来源回显，以及网络登记只读响应。
- D1/API 保存最多 16 个额外仓库；默认仓库固定保留，URL/repoId 分别唯一；installed package 唯一，同包跨仓明确确认。
- Flutter 添加先预览、再确认；刷新只读；移除保留安装引用和业务数据。四打开入口、Access 恢复、源迁移候选及阅读请求按完整来源解析。
- 扩展元数据与代码直接无凭据下载、拒绝重定向；共享 materials 与应用 HTTP 桥不随仓库切换。
- 可变存储、Cookie、D1 Source 设置和当前会话敏感值按来源隔离；外仓不能自报官方身份获得账户设置同步许可。
- 网络政策登记/继承/退役/同步按来源限定，跨仓 buildId 冲突拒绝；默认 CI 不清理其它仓库。
