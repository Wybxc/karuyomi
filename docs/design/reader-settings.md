# 非敏感阅读设置

同步设置覆盖应用主题、阅读模式、页组、图像适配、裁白、阅读背景、应用内调暗、点击区与键盘预设。Worker API + D1 是唯一业务权威，Web/iOS/Android 共用 `business.proto` 生成模型与标准 ProtoJSON。完整 P1 的实现与验收状态按 [P1](../plan/p1-library-and-progress.md) 分别维护。

## 全局默认与漫画覆盖

| 偏好       | 有类型的取值                                         | 作用域                              |
| ---------- | ---------------------------------------------------- | ----------------------------------- |
| 应用主题   | SYSTEM / LIGHT / DARK                                | 全局；SYSTEM 由各端跟随本机系统外观 |
| 阅读模式   | LEFT_TO_RIGHT / RIGHT_TO_LEFT / CONTINUOUS / WEBTOON | 全局默认，可逐漫画覆盖              |
| 页组       | AUTO / SINGLE / DOUBLE                               | 全局默认，可逐漫画覆盖              |
| 图像适配   | CONTAIN / WIDTH / HEIGHT                             | 全局默认，可逐漫画覆盖              |
| 裁白       | false / true                                         | 全局默认，可逐漫画覆盖              |
| 阅读背景   | BLACK / WHITE / THEME                                | 全局默认，可逐漫画覆盖              |
| 应用内调暗 | 0–80 的整数百分比                                    | 全局默认，可逐漫画覆盖              |
| 点击区     | STANDARD / REVERSED / DISABLED                       | 全局默认，可逐漫画覆盖              |
| 键盘       | STANDARD / REVERSED / DISABLED                       | 全局默认，可逐漫画覆盖              |

全局默认是 SYSTEM、LEFT_TO_RIGHT、AUTO、CONTAIN、裁白关闭、BLACK、调暗 0%、STANDARD 点击区与 STANDARD 键盘。AUTO 由客户端按实际可用宽度决定单双页，不同步设备宽度或当前计算结果；连续/Webtoon 不显示双页，但仍保留偏好，以便恢复分页模式。

漫画覆盖使用 `ReaderSettingsOverride` 的 optional 字段。字段缺省表示继承全局；显式 AUTO 表示覆盖为自动布局，不能当成继承。提交完整覆盖文档，未包含的字段恢复继承；空 `overrides` 清空全部覆盖。应用主题没有漫画覆盖。调暗覆盖的显式 0 表示不调暗，与缺省继承不同；D1 计算有效值时以字段 presence 合并，不能按数值真假选择默认值。裁白覆盖的显式 false 表示关闭，与缺省继承不同；D1 有效值保持真正的 JSON bool。全局变化会改变未覆盖字段的有效值，但不会修改漫画覆盖的 revision。

确认值比较遵循 IDL 字段语义：全局设置中的非 optional 标量按生成 getter 的有效值比较，标准 ProtoJSON 省略的 false/0 与显式默认值等价；三个列表仍保留顺序并核对所有字段。漫画 optional 覆盖继续核对 presence，显式 false/0 不能等同继承。相同 revision 的只读重取使用同一语义，实际值变化仍拒绝；mutation ID、CAS、ACK 后当前权威读回与原命令精确重试不变。

章节来源顺序已经随 `MangaResume.reversedOrder` 由进度链路保存，不再建立第二份设置权威。当前缩放/平移矩阵、视口尺寸、工具栏显隐、服务连接地址和平台资源状态不进入同步设置；Source 密码、token、Cookie 也不混入本协议。

Native 把用户明确选择且通过格式校验的 HTTPS 服务地址保留为本机启动偏好。没有可用偏好时使用构建的 `APP_ORIGIN` 默认值，或者由用户在设置页填写。选地址不代表登录成功；重新启动仍正常连接服务并校验 Access。Web 始终使用文档 origin。这个偏好仅保存连接地址，业务状态仍由该部署的 Worker API + D1 确认。

## 阅读内容与输入

背景使用黑色、白色或当前应用主题的背景色，相应状态文字保持可读。应用内调暗只给阅读内容叠加 0–80% 黑色遮罩；分页、连续/Webtoon 与独立图片放大窗口使用同一确认偏好，打开的放大窗口也跟随设置更新。工具栏、设置与显式导航仍保持可操作，不申请系统亮度权限。偏好变化不重新获取图片、替换章节或伪造观察位置。

点击预设用于分页模式的左右区域：STANDARD 沿阅读方向翻页，REVERSED 反转左右区域，DISABLED 关闭区域翻页；中央工具栏切换始终保留。滑动翻页与连续滚动维持各模式原有语义。

键盘预设覆盖方向键、PageUp/PageDown、空格、Home/End。STANDARD 保留现有方向语义；REVERSED 反转相对翻页，Home/End 仍定位绝对首末；DISABLED 消费这些阅读导航键而不导航。设置表单和其它路由的键盘交互不受影响。显式导航按钮始终保留，偏好变化保持当前图像逻辑锚与真实末页观察规则。

## 图像适配与二维位置

图像适配在分页、双页、连续和 Webtoon 使用同一含义，以 UI 实际解码尺寸和当前阅读视口计算。CONTAIN（完整显示）让每张图完整落入其分配区域；WIDTH（适宽）使图宽等于分配宽度，允许纵向溢出；HEIGHT（适高）使图高等于视口高度，允许横向溢出。双页适宽各分一半宽度；双页适高按每张真实显示宽度组成页组。连续模式保留纵向列表，超宽图片可横向浏览。未解码时只用占位比例安排布局，不将占位当作真实图片观察。

超出视口的内容必须可拖动到达；内容仍有可平移范围时，翻页手势不能抢走图片浏览，显式翻页控件仍可操作。缩放窗口使用当前适配偏好。默认 CONTAIN；漫画 optional 的显式 CONTAIN 表示覆盖完整显示，缺省才继承全局。

`ReadingAnchor` 在稳定页身份和原图纵向 `normalizedOffset` 外保存原图横向 `normalizedX`，以及该点的 `viewportX/viewportY`。四个坐标均为有限的 0–1 值，不保存设备像素或变换矩阵。原图坐标不随 RTL 反转，RTL 只改变页组顺序和阅读起止边。用户平移或滚动时从视口顶部阅读起始侧的最近可见图像点取锚；居中留白时保留该点实际的视口位置。切换适配、页组、模式、视口尺寸，学习真实尺寸或重开时，用相同页与原图点恢复，再约束到新布局的可达范围。服务端投影与客户端恢复保留二维坐标；最远进度仍按页身份投影后的来源顺序和原图 y 比较，x 不加入字典序排序。

观察依据当前 generation 已解码图片的实际矩形与视口交集，平移或缩放不因矩阵非单位就清除全部观察。自然完成仍由显式“读完本章”或“下一章”触发，且最后一页底边与阅读末边的交点必须实际可见；长图适宽顶部或宽图适高起始边刚出现不能使章节完成。图片只在 UI 解码，Source 宿主仍传输不透明编码字节。

## UI 裁白与原图坐标

裁白默认关闭；全局和逐漫画设置沿用同一确认链路。客户端直接使用精确锁定的 `image 4.12.0` 的 [`findTrim`](https://pub.dev/documentation/image/latest/image/findTrim.html)，只在 Flutter UI 检查实际显示的图像帧。Source、宿主、HTTP 与资源传输不增加图片识别或元数据处理。

采样复用显示图片的 ImageStream 和已解码图像句柄，不下载、不创建第二个 codec；将现有帧缩到长边最多 1024 的 RGBA 样本。仅不透明近白角（alpha ≥ 250，RGB 均 ≥ 240）进入库的颜色裁边，优先左上角，否则右下角；`fuzzy: 0.04` 容忍近白误差，`padding: 2` 保留采样像素余量。透明边、非白角、全白、动画后续帧或像素不可读时保持整图。读取最多等待三秒，失败继续整图阅读；这是可关闭的有界启发式，不承诺精确保留全部原像素，也没有目标设备性能结论。

样本识别结果是归一化原图 ROI，只在当前资源、generation 和实际解码尺寸匹配时使用；ROI 是可丢弃的 UI 派生状态，不同步像素框。每个图像组件最多一个采样任务，关闭或替换后丢弃迟到结果。现有资源 pool 在像素读取期间保持 pin；组件卸载后也等待任务结束才确认资源释放。动画暂停继续服从 Flutter 的 TickerMode 和减少动态效果设置。

显示使用 ClipRect 和原完整图的位置偏移，不重编码、不生成裁后图片。ROI 有效比例参与单双页分组、适配、连续/Webtoon 和放大窗口；完整解码尺寸与内存预算不因裁白缩小。待 ROI 确认前不发布阅读观察或完成；失败的整图 ROI 解除等待。保留已学比例稳定列表布局，但资源重新就绪前仍不能伪造观察。

锚和 observed 始终保留原图 x/y，ROI 坐标只用于显示几何映射；裁掉的锚约束到最近可见内容点，关闭裁白按同一原图点恢复。自然末端依据有效 ROI 的底边与阅读末边，所以裁白后的原图 observed y 可能小于 1；仍须最后一页的有效末角实际可见并显式操作才完成，不能把裁白开关当作翻页或读完操作。当前工程证据与实际平台限制见[裁白记录](../verification/reader-crop.md)。

## API 与原子状态

- `GET /api/settings` 返回全局设置与有效阅读默认值。
- `GET /api/settings/manga/:mangaKey` 用同一 SQL 快照读取全局、该漫画覆盖与 account revision，并返回合并后的 `effectiveReader`。不存在覆盖时仍返回该漫画的 revision 0 和空覆盖；读取不建行，也不要求收藏或写入漫画资料。
- `POST /api/settings/mutations` 接受 `setGlobal` 或 `setManga`，请求带 UUID 与目标作用域的 `expectedRevision`。沿用受信 Access subject、绑定身份的 `X-App-Subject`、Origin、写标识和业务正文预算。

全局和每漫画各有独立 revision，避免普通阅读进度或另一漫画设置造成无关 CAS 冲突；成功写入统一提升 account revision，不改变漫画业务 revision、进度、resume 或 epoch。`reader_settings` 按 subject 和作用域唯一，清空覆盖保留空文档及递增 revision，旧请求不能复活覆盖。

设置值、作用域 revision、account revision 和 `kind=settings` 的幂等结果经条件 SQL、唯一约束及 nonce gate 在同一 D1 batch 提交。确认响应在事务最后读取当前全局/覆盖并计算有效值，避免另一作用域并发变化时拼接旧默认和新 account revision。相同 UUID/正文返回原确认；同 UUID 不同内容或跨业务消息复用明确冲突。

## 客户端确认与恢复

每个作用域的编辑基于已确认 revision，首次发送后 UUID、正文和 CAS 固定。不确定写入只显式重试原命令，只读刷新不能偷偷重发；确定冲突后重新读取当前作用域再编辑。幂等成功仅证明原写入发生过，客户端重新 GET 当前作用域并核对提交值，不能用旧确认覆盖其它端之后的修改。

私有 API 的当前请求遇到 401、403、登录重定向或 HTML 登录页时，由宿主沿正式控制错误返回 Access required/denied，Dart 发布既有运行时事件，业务 UI 随即进入登录或拒绝状态；即使未打开任何 Source 也如此。已发布图片继续保留到 UI 正常释放。认证恢复只核对身份和读取当前状态，不自动重放待确认设置；同身份显式重试仍使用原命令。旧 Source generation 或已销毁宿主的迟到 Access 响应不改变替代会话；普通业务 HTTP 错误与公共静态资源失败保留原 HTTP 语义。

全局与漫画设置读取、合并和 UI 应用须保持身份绑定；服务/身份变化使旧编辑失效，迟到结果不能更新新会话。布局设置变化保持原图逻辑锚，不能把设置刷新当成跳到另一设备阅读位置。请求失败仍可继续已加载阅读；未确认草稿只保存在当前会话，不承诺关闭后恢复。

全局设置页显式提交完整偏好，未编辑的表单跟随新确认快照；开始编辑后保留最初 revision，不能因后台刷新悄悄抬高 CAS。阅读页快捷选择保存为漫画覆盖，弹窗允许每项“跟随全局”；AUTO 始终保留显式 presence。待确认时禁用设置编辑和提供原操作重试，已加载阅读可继续。重新打开编辑器显示待确认命令的实际值。

同一服务的显式重连保留业务客户端与当前会话未确认命令，地址有无尾斜杠视为同一服务；重建运行时后先通过 bootstrap 核对身份，再只读刷新，不自动重发设置操作。Native 更换地址时先用正式平台构造器解析和验证候选配置，拒绝无效地址时保留旧会话、待确认命令和恢复入口；候选未被采用时负责释放。真正切换服务或 bootstrap 确认身份改变后，旧设置编辑立即失效，不能向新身份重试。

连接确认、进入设置页、恢复前台和同身份重连时只读刷新。全局确认变化触发当前漫画重新读取有效设置，保留显式覆盖；来源顺序继续由阅读进度管理。父级应用设置、窗口变宽及切章不产生保存回调，迟到 viewport 数据不能覆盖父级偏好。成功确认的设置从服务端恢复，不在客户端另建权威偏好文件。
