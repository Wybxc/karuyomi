# 路由与页面布局

`CupertinoApp.router` 和 go_router 负责 Web 地址及浏览器历史。侧栏、底栏和可独立进入的页面共用同一份路由状态。宽屏作品详情显示在右侧，窄屏使用整页。改变视口尺寸不重新打开作品。

| 页面                         | 路径示例                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- |
| 书架、历史、浏览、扩展、设置 | `/app/library`、`/app/history`、`/app/browse`、`/app/extensions`、`/app/settings`                        |
| 漫画源和跨源搜索             | `/app/browse/source/<package>/<sourceId>`、`/app/browse/search`                                          |
| 扩展详情、仓库和本机存储     | `/app/extensions/item/<catalogKey>/<package>`、`/app/extensions/repositories`、`/app/extensions/storage` |
| 设置详情                     | `/app/settings/reading` 等                                                                               |
| 作品和章节                   | 在所属入口追加 `/manga/<mangaKey>`，再追加 `/read/<chapterKey>`                                          |
| 书架直接续读                 | `/app/library/read/<mangaKey>/<chapterKey>`                                                              |

进入作品或阅读时保留所属入口，用于返回。浏览器前进后退恢复历史中的目标。通过站内链接进入时，返回使用已有的上一级历史记录；从外部直达时，站内返回取路由定义的上一级。阅读内切换章节更新当前地址及历史条目。滚动、搜索输入、未保存设置和弹窗由各自页面持有。

作品路径只含既有作品键。重开时通过当前账号的书架资料或浏览记录取回原漫画源快照，包括未收藏但已记录的作品。缺少记录时在目标页说明原因。章节从漫画源当前提供的清单匹配，包含按清单标识的重复章节条目。已保存阅读位置和阅读设置由账户恢复。路由不传递上游地址、会话凭据、图片资源标识或运行时代次。

Worker 对 `/app` 和 `/app/` 下的 GET、HEAD 返回同版本 Flutter 入口。API、登录回调和扩展材料由各自的路径处理。进入深链接时在原地址完成身份确认；路由取回的业务状态只属于当前账号。当前链接的恢复依赖账号能访问该漫画源和该作品记录。

实施和验收进度见[计划](../plan/url-navigation.md)。
