# 书架续读与详情失败恢复

书架保留整卡打开详情的入口，并在有服务端已确认继续阅读记录或当前会话未保存草稿时提供独立续读操作。业务权威仍是 Worker API + D1；书架中的 resume 只是一份已确认视图，不在客户端建立第二份进度表。

## 书架续读

先按收藏中的 package/source 身份从当前静态索引取得扩展，使用原完整 Manga 快照读取最新详情与章节。构造完整 `ChapterSequence`，只按稳定 chapterKey 解析目标，不依标题、章节号或旧显示序号猜测匹配。已确认视图可能落后于另一设备，点击后重取当前服务端 resume；同一身份当前会话尚未确认的阅读草稿仍保留，并明确显示未保存状态。

匹配成功后走正式 `ChapterReaderRoute`。章节级锚点、manifest 变化与来源顺序的恢复继续由正式进度控制器完成，书架入口不复制恢复或图片调度逻辑。不再匹配的章节回到当前详情并给出说明，用户可以明确选择章节；读取失败不伪造“从未阅读”或自行打开首章。

普通选页已经明确目标页及其首选放置；迟到的解码尺寸可以调整显示和已观察位置，不能仅因居中或边界限制而改写同一个原图点的视口锚。实际拖动或显式二维跳转仍提交新位置；最远位置只使用真正解码并进入视口的图像观测。

打开流程只允许当前页面、业务身份与 Source 会话使用其结果，重复点击互斥。异步结果返回时页面已关闭、身份变化或 Source 会话已替换，则放弃导航并释放尚未交给 Reader 的章节资源。返回书架后重新取得已确认状态。

从书架打开作品时，Source 名称、语言和完整 Manga 快照与已确认书架项均未变化，就不发送资料更新，也不推进共享作品 revision。保留不透明 memo 和 optional 字段的 presence 比较，真正变化仍沿原 CAS 更新；旧书架快照与 Source 相同不会回写覆盖另一端的新资料。跳过无差异更新不会清除尚未确认的原资料命令，显式重试入口继续保留。

## 显式失败恢复

普通 Source 开章失败保留本次明确选择的稳定章节及错误，在详情提供显式重试。重试再次调用正式 Source 章节入口，不定时重发，不把普通 Source 错误归类为 Access 失效；Access 暂停和认证仍使用现有独立流程。选择其它章替代旧的失败目标；旧身份或已失效详情不能继续使用该重试。

续读位置读取失败提供独立的只读重取操作，与“重试保存进度”分开。读取不会 flush 尚未确认的进度，不能借刷新重放业务写入或 Source 请求。当前会话草稿的恢复与提交沿现有明确路径处理，不冒充已经服务端确认。

从书架打开作品的附带元数据更新也不能隐式重试另一项未确认业务命令。元数据未能确认时保留原操作和原请求身份，仍允许按已取得的 Source 详情阅读，并给出失败信息。书架提供专用“重试保存书架资料”，只重试该作品原有的 metadata 命令，复用原 UUID、CAS 与正文；不能通过这个入口发送其它未确认修改。确定的冲突只读刷新后再按最新状态决定。

实施状态维护在 [P1](../plan/p1-library-and-progress.md)，工程证据与实际运行门在验证记录中分别维护。
